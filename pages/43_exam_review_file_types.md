# Exam Review: File Types

---
layout: top-title-two-cols
color: blue-light
zoom: 1.3
---

::title::

# Text files

::left::

**Advantages**

- Simple to create and read in any editor
- Small, with no special software needed
- Flexible layout, chosen by the programmer

::right::

**Disadvantages**

- No built-in structure, so the program needs its own code to read each line
- Poor for related or complex data
- Finding or changing one item usually means reading the whole file

::title::

# CSV files

::left::

**Advantages**

- Compact and easy to read and write in code
- Opens directly in spreadsheet software
- Widely supported for import and export

::right::

**Disadvantages**

- Flat tables only, with no nested data or relationships
- Commas, quotation marks and line breaks inside data need special handling
- Header row, delimiter and encoding are conventions, not rules

::title::

## XML files

::left::

**Advantages**

- Stores hierarchical (nested) data
- Tags describe the data, so the file is self-explanatory
- Can be validated against a schema

::right::

**Disadvantages**

- Verbose, so files are much larger than the equivalent CSV
- Slower to read and write
- Harder to produce and read by hand
- Strict syntax so one missing or mismatched tag can make the file invalid
